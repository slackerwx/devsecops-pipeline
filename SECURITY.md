# Security policy

## Reporting a vulnerability

Open a private report at https://github.com/slackerwx/devsecops-pipeline/security/advisories/new.
Do not open a public issue for suspected vulnerabilities in the pipeline itself.

## Supported versions

The latest `v1.x.y` release. Consumers should pin the workflow by commit SHA and let Renovate
(`renovate/consumer.json`) move the pin.

## What this repo does to protect its consumers

See `docs/security-model.md`.
